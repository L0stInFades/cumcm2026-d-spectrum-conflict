# 时频冲突检测与消解（CUMCM 2026 D 题）

本仓库是 2026 年高教社杯全国大学生数学建模竞赛 D 题的完整研究工程：原始题目与附件、云端流水线、模型与求解程序、测试、论文源码与交付物。所有数据处理、计算、绘图、排版与打包均在 Modal 云端按固定镜像执行；本地只做文本编辑、Git 操作、任务提交、下载与散列校验。

## 内容

- `docs/ENGINEERING_STANDARD.md`：工程规范（阶段/清单/契约/门禁/发布）。
- `docs/MODELING_STANDARD.md`：建模与写作标准、审稿清单。
- `docs/problem_brief.md`：题目分析与建模路线。
- `docs/mdr/`：建模决策记录；`docs/adr/`：工程决策记录。
- `pipelines/d/`：本题的全部模型、求解与结果生成程序。
- `manuscript/`：论文源码；`releases/<tag>/`：论文 PDF、结果工作簿、支撑材料与 SHA-256 清单。

## 复现

```bash
python3 tools/cli.py provision
python3 tools/cli.py run ingest,validate --new-run
# 科学阶段见 docs/RUNBOOK.md 与 pipelines/d/stages.py
python3 tools/cli.py run lint,test,paper,qa,package,release
python3 tools/cli.py release --version <tag>
```

## 结果概要

来自云端运行 `20260912-212914-2b9c081`（15 个阶段全部 `completed`）；完整数值、图表目录与局限见 `docs/RESULTS.md`，
三位独立审稿人的 46 条意见与逐条处理见 `docs/REVIEW_RESPONSE.md`。

| 问题 | 关键结果 | 最优性 |
|---|---|---|
| 1 冲突检测 | 150 个用频计划中检出 **297 对**时频冲突，涉及 148 个计划、587 个使用次 | 精确；两种算法互验 + 独立单元格校验器 |
| 2 冲突消解 | 保留 14 / 调整 124 / **撤销 12**（A、B 类零撤销） | 撤销三级 (0, 0, 12) 经 CP-SAT **证明最优**；固定撤销集合后调整四级亦证明最优；调整各级的无条件界只报值与下界 |
| 3 新增 C 类 | 在问题 2 方案上最多再安排 **109** 个 C 类计划 | CP-SAT 界 = HiGHS LP 界 = HiGHS MILP 界 = 109，**gap = 0** |
| 4 允许改间隔 | 保留 17 / 调整 125 / **撤销 8**（较问题 2 少三分之一），且**不增加时频资源**（最晚结束时刻仍为 643） | 撤销 A、B 两级证明最优；固定撤销集合后调整四级证明最优；去掉资源守恒约束的变体一并报告 |

检验：四个与求解器分离的独立校验器全部通过；24 个微型实例与穷举最优一致（其中 7 个的撤销层非零）；
HiGHS 独立建模交叉验证；冲突图最大独立集给出与消解模型完全无关的下界；
另跑一次不加载现任解的冷启动，如实报告其结果不及热启动（见论文第 5.4 节）；`qa` 16 项门禁全部通过。

局限（详见论文第 9 节）：调整各级的无条件对偶间隙仍较宽，只报"值 / 证明下界 / 状态"；
问题 3 的答案依赖于采用哪一个问题 2 方案（四个合法方案上实测 109--145）；
问题 4 的"不增加时频资源"是本文自加的解释，题面未写明，故两种读法的结果都给出。

交付物见 `releases/v1.0.0/`：论文（正文 30 页 + 附录，共 180 页）、`result1--4.xlsx`、支撑材料与《AI工具使用详情.pdf》，
全部文件的 SHA-256 记录在 `release_manifest.json` 中并已本地核对一致。
