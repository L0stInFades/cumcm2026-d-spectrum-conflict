# 建模与写作标准（目标：SIAM 应用数学期刊级的严谨性，CUMCM 论文格式）

## 1. 建模流程（每个问题都必须完整走一遍）

1. **形式化**：用数学语言精确定义对象、变量、约束、目标；指出题目中的歧义并在 MDR 中给出解释与备选。
2. **假设**：编号；每条给出物理/业务依据与被违反时的后果；区分"题目给定"与"本文附加"。
3. **模型**：从守恒律 / 组合结构 / 概率结构出发推导；给出量纲检查与极限情形（退化成已知结果）。
4. **求解**：算法伪代码（algorithm2e），复杂度，收敛/终止条件；求解器版本与参数固定。
5. **验证与确认（V&V）**：
   - 微分方程：解析解或制造解对照（误差量级）、网格与时间步收敛表（观测阶数）、守恒量检查、最大值原理/单调性检查、时间步无关性。
   - 组合优化：独立可行性校验器（与求解器代码分离）；最优性证明或界（LP 松弛、对偶、求解器 gap）；小规模实例穷举对照；两个不同求解器交叉验证；确定性（同种子同解）。
   - 统计/预测/决策：时间序列交叉验证或滚动回测（MAE、MAPE、pinball loss、区间覆盖率）；分类稳健性（不同阈值/方法一致率）；决策的样本外对照与反事实比较。
6. **结果**：按题目要求的表格格式给出；数值保留四位小数；每个数字来自 `\val` 宏或生成表格。
7. **灵敏度与不确定性**：关键参数 ±10%/±20% 的弹性；歧义解释的备选结果；给出区间而不只是点估计。
8. **局限**：明确说明未建模的机制与可能的偏差方向。

## 2. 数学表达

- 符号表完整，单位一致（SI，使用 siunitx）；每个方程编号并在文中被引用。
- 定理/命题/引理用 amsthm 环境，证明完整或给出可核查的引用。
- 离散化写明网格、边界处理与阶数；优化模型写明决策变量、约束、目标与线性化/词典序处理方式。

## 3. 图表

- 图：矢量 PDF；坐标轴带单位；图注自成一体（不看正文也能读懂）；色板色盲友好；不用三维饼图等装饰性图形。
- 表：booktabs 三线表；列头带单位；同一表内小数位一致；大表放附录，正文放摘要表。
- 每张图表在正文中至少被引用一次；未被引用的图表不得进入论文。

## 4. 写作

- 摘要：一页以内；包含问题、方法、关键定量结果（含数值）、检验结论与关键词；不写空话。
- 正文：主语明确、因果清楚；先说结论再给证据；每节首段概述本节要回答的问题。
- 引用：GB/T 7714 格式（BibTeX gbt7714）；只引用真实、可核查的文献，优先经典教材与同行评审论文。
- 禁止：未定义的符号；无单位的物理量；无不确定性的预测；"显然""众所周知"；与结果文件不一致的数字。
- 身份信息：正文、附录、支撑材料均不得出现作者、学校、赛区、队号。

## 5. 审稿清单（评审代理逐条核对）

1. 每个问题的答案是否直接、完整地回答了题目要求（含表格格式与结果文件）？
2. 模型假设是否被使用且被验证？是否有假设与数据矛盾？
3. 数值/优化/统计结果是否有独立校验？收敛/最优性/回测证据是否在论文中？
4. 论文中的数字是否与 `results` 与 `numbers.json` 一致（抽查 ≥ 10 处）？
5. 歧义解释是否明确并有备选分析？
6. 灵敏度分析是否覆盖关键参数？结论是否稳健？
7. 图表是否规范、被引用、可读？
8. 参考文献是否真实？引用是否恰当？
9. 格式：摘要 1 页、正文 ≤ 30 页、附录含完整程序与文件清单、无身份信息、AI 使用说明。
10. 写作：是否存在夸大、含糊、自相矛盾的表述？
