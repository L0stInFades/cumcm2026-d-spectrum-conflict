# D 题简报：时频冲突检测与消解（区间冲突图、优先级词典序整数规划、装箱式打包）

## 1. 数据与形式化

150 个计划：A 类 20 个（频宽 10，时长 5，间隔 60，3 次），B 类 40 个（频宽 15，时长 3，间隔 40，4 次），C 类 90 个（频宽 3，时长 2，间隔 8，12 次）。频段共 100 个（[0,100)）。

计划 i：频段 [f_i, f_i+w_i)；第 k 次使用（k=0,…,n_i−1）的时间区间 [s_i + k(d_i+g_i), s_i + d_i + k(d_i+g_i))，其中 d_i 为时长、g_i 为间隔（示例：[35,40)、间隔 60 → 第二次 [100,105)）。

冲突：存在 k,l 使时间区间相交且频段区间相交（半开区间）。

## 3. 目标函数（必须写 MDR，并做备选分析）

题目优先级："尽可能减少撤销；尽量减少被调整数量；高优先级尽量保持；尽量减少调整幅度；最大平移 10Δf、5Δt"。推荐主方案：词典序
(1) 撤销数量按类别权重（A≫B≫C）→ (2) 调整数量按类别权重 → (3) 调整幅度总和（频移 |δ|/10 与时移 |τ|/5 归一化后求和）。
用 CP-SAT 依次固定前一层最优值求解下一层（或用足够分离的权重并证明等价）；求解器状态必须为 OPTIMAL。备选：先总撤销数再总调整数；纯加权。论文给出各方案的 Pareto 对照表。

## 4. 算法与验证

- 检测：O(n² m²) 直接法（n=150, m≤12 可瞬间完成）+ 扫描线 O(N log N) 版本，说明可扩展性；两者结果必须一致。
- 消解：预计算每对计划各选项组合是否冲突 → 布尔变量 y_{i,o} + 冲突约束 y_{i,o}+y_{j,o'}≤1（可用 AddAtMostOne 与团约束加强）；CP-SAT（多线程）与 HiGHS MILP 交叉验证同一模型；独立校验器重新对调整后计划做冲突检测（必须为 0）并检查幅度与"只改一参数"约束。
- 问题 3：变量 x_{f,s}（新增计划的频段起点 f∈[0,97] 与首次时间起点 s∈[0, T_end−112]）；单元格容量约束（每个 (频段, 时隙) 至多被一个占用者覆盖）；目标 max Σx；给出 LP 上界与 CP-SAT 解，报告 gap；另给"允许既有计划任意平移"的扩展解释作为上界讨论（MDR）。
- 问题 4：在问题 2 模型中为 C 类增加间隔选项；注意间隔改变会改变结束时刻 T_end，与问题 3 的资源区域定义保持一致说明。
- 理论：给出"保持/撤销决策等价于冲突图最大权独立集"的命题与 NP-难性说明；给出检测复杂度命题。
- 随机小实例（n≤12）穷举对照消解最优值；确定性（同种子同解）；求解时间与规模关系（n=150…1500 合成实例）。

## 5. 论文必须包含

冲突图可视化（时频平面甘特图，冲突对高亮）、消解前后对照图、问题 3 布局图、各问题统计表、最优性证明/界、备选目标的对照、局限（离散化粒度、优先级权重主观性）。
