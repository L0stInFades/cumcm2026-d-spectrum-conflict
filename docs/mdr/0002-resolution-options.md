# MDR-0002 消解动作集合与约束

日期：2026-09-12 · 状态：已采纳 · 关联问题：问题 2、4

## 问题
"一个用频计划只能调整其中一个参数或撤销"；"一般不调整使用次数和使用间隔时长"；"频段、时间调整的最大平移幅度分别为 10Δf、5Δt"。需要明确可选动作集合及其边界条件。

## 备选方案
1. 每个计划恰选一项：保持；频段平移 δ∈{−10,…,10}\{0} 且 0 ≤ f+δ、f+δ+w ≤ 100；时间平移 τ∈{−5,…,5}\{0} 且 s+τ ≥ 0（整个使用序列同步平移，间隔与次数不变）；撤销。问题 4 另允许 C 类计划把间隔改为 g'∈[g−10,g+10]∩[1,∞)\{g}（其余参数不变）。
2. 允许同时平移频段与时间：违反"只能调整其中一个参数"。
3. 允许频段平移越出 [0,100)：违反"有限带宽"设定。
4. 时间平移只允许向后（τ>0）：题目未限制方向；向前平移只要 s+τ ≥ 0 即可。

## 决策与理由
采用方案 1。所有幅度取整数（Δf、Δt 为基本单位）。间隔 g' ≥ 1 是本文附加假设（间隔为 0 意味着相邻两次使用合并成一次，改变了"使用次数"的语义）。问题 4 不对调整后计划的结束时刻设上限（题目未要求"不增加时频资源"），但论文报告调整后最晚结束时刻以便与问题 3 的资源区域对照。

## 对结果的影响与验证
独立校验器逐计划检查：恰有一个动作；调整后与原计划恰有一个参数不同；|δ| ≤ 10、|τ| ≤ 5、|g'−g| ≤ 10、g' ≥ 1；边界条件；调整后计划集合零冲突。灵敏度分析改变 (10,5) 上限观察调整数量的变化。
