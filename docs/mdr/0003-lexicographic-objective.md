# MDR-0003 消解目标：类别加权的词典序目标与备选方案

日期：2026-09-12 · 状态：已采纳（求解方式经 **MDR-0008** 与 **MDR-0009** 细化） · 关联问题：问题 2、4

## 问题
题目依次给出："应尽可能减少撤销用频计划；尽量减少被调整的用频计划数量；A 类优先级最高、B 类其次、C 类最低，高优先级用频装备的用频计划应尽量保持；尽量减少调整的幅度"。这是四条彼此可能冲突的目标，题目未给权重。

## 备选方案
1. **P（主方案，类别内嵌的七级词典序）**：(撤销 A, 撤销 B, 撤销 C, 调整 A, 调整 B, 调整 C, 总幅度)，逐级取最小。理由："高优先级应尽量保持"在撤销与调整两个层面都优先保护高优先级装备。
2. **T（总量优先）**：(撤销总数, 调整总数, 变动 A, 变动 B, 变动 C, 总幅度)，其中变动 = 撤销 + 调整。理由：把优先级只作为总量相同时的次级偏好。
3. **S（无优先级）**：(撤销总数, 调整总数, 总幅度)。用于量化优先级条款的作用。
4. **W（纯加权）**：min Σ_i w_{c(i)}(10·撤销_i + 3·调整_i) + 幅度_i，w=(A:3, B:2, C:1)，幅度归一化为 |δ|/10 + |τ|/5 + |Δg|/10。

## 决策与理由
主方案 P；备选 T、S、W 全部求解并在论文给出 Pareto 对照表。幅度统一归一化：频段 |δ|/10、时间 |τ|/5、间隔 |Δg|/10（以各自最大允许幅度为分母），求解时按 ×10 的整数（|δ| + 2|τ| + |Δg|）建模。词典序用逐级固定前级最优值的顺序求解实现，每级要求求解器状态为 OPTIMAL；同时用"分离权重的单目标"求解验证向量一致（权重严格大于后续各级取值范围之和，等价性有证明）。

## 对结果的影响与验证
若各方案的目标向量相同，说明结论对优先级解释稳健；若不同，论文给出差异并解释取舍。所有方案的解都经独立校验器复核。

## 补充（2026-09-12）

1. 本记录要求"每级求解器状态为 OPTIMAL"。实测该实例的"调整数量"与"幅度"各级在可承受预算内无法证明最优，MDR-0008 因此改为"到时以最好可行值固定该级并记录证明下界"，MDR-0009 进一步以现任解上界割保证报告值不劣于任何已知可行解。论文按"值 / 证明下界 / 状态"如实报告：本轮问题 2 的撤销三级 (0, 0, 12) 与问题 3 的 109 已证明最优，其余各级未证明。
2. 本记录预期"若各方案向量相同则结论稳健"。实测四个方案**不相同**：P 撤销 12 个全部为 C 类；T 与 S 把撤销总数降到 8，但代价是撤销 2–1 个 A 类与 6–7 个 B 类。这恰好量化了题目优先级条款的作用——P 是唯一在问题 2 与问题 4 中都不撤销任何 A、B 类计划的方案，因此本文采用 P。对照表见 `tab_q2_schemes` / `tab_q4_schemes` 与 `docs/RESULTS.md` 第 8.5 节。
