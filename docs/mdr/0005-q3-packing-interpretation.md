# MDR-0005 问题 3 的解释：在问题 2 方案上最大化新增 C 类计划数

日期：2026-09-12 · 状态：已采纳 · 关联问题：问题 3

## 问题
"基于问题 2 求解得到的无冲突用频计划，如果不限制频段和时间的平移幅度，在不增加时频资源的前提下，最多还能安排多少 C 类用频装备？"需要明确：(a) 既有计划是否固定；(b) 新增 C 类计划的参数；(c) "不增加时频资源"对应的区域；(d) 新增计划之间是否也须无冲突。

## 备选方案
1. **主解释**：问题 2 的无冲突方案（保留与调整后的计划）固定不动；新增 C 类计划与附件中 C 类参数相同（频宽 3、时长 2、间隔 8、次数 12），其频段起点 f∈[0,97] 与首次时间起点 s 可任意选择（"不限制平移幅度"）；资源区域为 100 个频段 × [0, T_end]，T_end 为问题 2 方案中最晚的结束时刻；新增计划彼此之间及与既有计划均无冲突；目标为新增数量最大。
2. 允许既有计划再次任意平移以腾出空间：这是一个更大的联合优化，其最优值 ≥ 主解释；论文以"上界讨论"给出其松弛界（自由单元容量界 ⌊自由单元数/72⌋ 与 LP 界），不作为主结果。
3. T_end 取附件原始计划的最晚结束时刻（643）：与主解释仅在问题 2 时间平移改变最晚结束时刻时不同；作为灵敏度对照报告。

## 决策与理由
采用方案 1；"基于问题 2 求解得到的无冲突用频计划"表明既有方案是给定输入，"不限制平移幅度"修饰新增计划的放置自由度。新增计划的时间区间写入 result3.xlsx 的 C 列为首次使用区间 [s,s+2)，间隔 8、次数 12 与既有 C 类一致。

## 对结果的影响与验证
独立校验器复核：新增计划参数、边界、与既有计划及彼此零冲突。最优性证据：CP-SAT 最优状态或其上界、HiGHS LP 上界、自由单元容量界；报告 gap。方案 3 的结果作为灵敏度给出。
