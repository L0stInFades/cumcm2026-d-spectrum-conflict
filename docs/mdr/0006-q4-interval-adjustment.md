# MDR-0006 问题 4：C 类间隔时长调整作为附加动作

日期：2026-09-12 · 状态：已采纳 · 关联问题：问题 4

## 问题
"若允许部分 C 类用频装备对用频间隔时长进行调整，但要求与原间隔时长的差异不超过 10Δt"。需要明确该动作与"只能调整其中一个参数"的关系、取值范围、幅度度量以及目标函数。

## 备选方案
1. 间隔调整是 C 类计划的第五种动作：g'∈[g−10,g+10]∩[1,∞)\{g}，频段、首次时间区间、次数不变；它计入"调整数量"，幅度记 |g'−g|/10；目标仍为 MDR-0003 的主方案 P，其余类别动作集合与问题 2 相同。
2. 间隔调整可与平移叠加：违反"只能调整其中一个参数"。
3. 只允许缩短间隔：题目未限制方向。

## 决策与理由
采用方案 1。由于问题 4 的动作集合是问题 2 的超集，其最优目标向量在词典序意义下不劣于问题 2（性质测试），差异即"允许调整间隔"的收益。间隔改变会改变结束时刻，论文报告调整后的最晚结束时刻以与问题 3 的资源区域对照。

## 对结果的影响与验证
独立校验器额外检查 g' 范围与 g' ≥ 1，以及仅 C 类使用该动作；与问题 2 逐类别对照给出表 1 格式统计。

## 本轮结果与一个必须在论文中说明的后果

问题 4 的解为 (0, 0, 9, 13, 36, 78, 776)，在词典序上优于问题 2 的 (0, 0, 12, 16, 37, 71, 750)（`QfourLexNotWorse` = 通过），收益是**撤销数由 12 降到 9**（−25%），代价是多调整 3 个计划、归一化幅度 +2.6。31 个 C 类计划改变了间隔，平均 |Δg| = 4.90、最大 10。

**后果**：间隔变长会把最后一次使用推后，问题 4 方案的最晚结束时刻为 **718**，比问题 2 的 643 长 75Δt（`QfourHorizonDelta`）。因此：

- 若"在不增加时频资源的前提下"被理解为时间范围也不得延长，则问题 4 的这个解实际上**占用了更多的时频资源**，与问题 3 的资源区域定义不一致。论文必须明确指出这一点，并说明本文的立场：题目对问题 4 并未提出"不增加资源"的约束（该约束只出现在问题 3 中），故不对最晚结束时刻设限；但为便于对照，报告 `QfourHorizonAfter` = 718 与 `QthreeHorizon` = 643。
- 若需要限制，可在模型中加入 `p.end <= 643` 的硬约束重解；本轮未做，列为局限。
