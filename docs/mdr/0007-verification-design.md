# MDR-0007 验证与确认（V&V）设计

日期：2026-09-12 · 状态：已采纳 · 关联问题：全部

## 问题
组合优化结果需要与求解器分离的证据：可行性、最优性、确定性、可扩展性、对解释与参数的稳健性。

## 决策
1. **独立校验器**（pipelines/d/validators.py）：不复用检测/求解代码，把每个计划展开为时频单元格集合，用集合求交判定冲突；逐计划检查动作合法性与"只改一参数"；重新计算表 1 统计与目标向量并与求解器报告比对。报告写入各阶段目录，results 阶段在写工作簿前要求全部通过。
2. **最优性证据**：CP-SAT 每级 OPTIMAL；HiGHS 独立建模得到相同目标向量；LP 松弛界；问题 3 报告上界与 gap。
3. **穷举对照**：随机小实例（≤ 6 个计划、缩小的动作集合）穷举全部动作组合求词典序最优向量，与 CP-SAT 结果比对。
4. **确定性**：同参数重复求解，目标向量与解相同。
5. **可扩展性**：合成实例 n=150…1200（时间范围随 n 等比放大以保持密度），记录检测与求解时间。
6. **灵敏度**：最大平移幅度 (10,5) 变化、目标方案 P/T/S/W 对照、问题 3 的 T_end 取法对照。
