# MDR-0010 问题 3 中"不限制平移幅度"的解释：固定既有计划 vs 联合重排

日期：2026-09-12 · 状态：已采纳 · 关联问题：问题 3（并影响问题 2 结果的使用方式）

## 问题

题目原文（问题 3）：

> 基于问题 2 求解得到的无冲突用频计划，**如果不限制频段和时间的平移幅度**，在不增加时频资源的前提下，最多还能安排多少 C 类用频装备？给出相应的用频计划，将结果保存到文件 result3.xlsx 中。

"不限制频段和时间的平移幅度"一句指向"平移"，而**新增**的 C 类装备并没有"原位置"可供平移——它们是被"安排"的。因此这句话有两种解释：

- **解释 A（新增计划不受幅度上限约束）**：问题 2 的方案原样保留；新增 C 类计划可放在 100 × [0, T_end] 区域内任意 (频段起点, 首次时间起点)，不受 10Δf / 5Δt 的约束。此时"不限制平移幅度"是对新增计划放置自由度的说明。
- **解释 B（既有计划可再任意平移）**：以问题 2 的无冲突计划集合为出发点，允许其中的计划**不受 10Δf / 5Δt 限制地再次平移**（频段宽度、时长、间隔、次数均不变），以便腾出空间；在同一 100 × [0, T_end] 区域内最大化新增 C 类计划数。

两处文本证据相互矛盾：(i) "平移"一词只对既有计划有意义，支持 B；(ii) 结果模板 `result3.xlsx` 只有"序号、频段区间、时间区间"三列且说明为"将新增的 C 类用频装备逐一填写"，并未要求记录既有计划的新位置，支持 A。

## 备选方案

1. 只做解释 A。风险：若命题意图为 B，报告的数量会被严重低估（本轮 A 为 100，B 的面积上界为 678）。
2. 只做解释 B。风险：与结果模板不符——`result3.xlsx` 无处记录既有计划被移动到哪里，评阅无法复核既有计划仍然无冲突。
3. **采纳：以 A 为主解释填写 `result3.xlsx`，同时把 B 作为正式的备选分析给出可核查的上下界。**

## 决策与理由

采纳方案 3。理由：

- **主解释 A 与交付物一致**：`result3.xlsx` 的三列恰好是新增计划的完整描述；A 的解答可被评阅者仅凭 result2.xlsx + result3.xlsx 独立复核。A 下的最优值由 CP-SAT、HiGHS MILP 与 HiGHS LP 三者共同证明（三个上界均等于解值，gap = 0）。
- **备选 B 以严格的上下界给出，不做无依据的点估计**：
  - **上界（命题）**：平移不改变任一计划占用的单元数（w·d·n 不变），故无论既有计划移到哪里，被占用的单元总数 S 是常数；区域共 100·T_end 个单元，每个新增 C 类计划恰占 w·d·n = 3·2·12 = 72 个单元，故新增数量 ≤ ⌊(100·T_end − S)/72⌋。该界对 A 与 B 同时成立，键 `QthreeFreeCellBound`。
  - **下界（构造）**：任何一个可行布局都给出 B 的下界。本文用"最大优先的首次适配"（first-fit decreasing：按占用单元数降序把既有计划逐个放到最靠前的可行 (f, s)）重排既有计划，再在剩余自由单元上用与主解释相同的 CP-SAT 装填模型求新增 C 类计划的最大数量；该数量经同一独立校验器复核（既有计划之间、既有与新增之间、新增之间均零冲突，且每个既有计划的 w、d、g、n 不变）。键 `QthreeAltRepackNewPlans`、`QthreeAltRepackBound`。
  - A 的最优值本身也是 B 的一个下界（问题 2 的布局是 B 的一个可行布局）。
- **论文写法**：正文按 A 报告最优值并给出最优性证明；在同一节以"若题意为 B"的方式给出 [下界, 上界] 区间与构造图，并说明两种解释的差别来源。

## 对结果的影响与验证

- 解释 A：新增 `QthreeNewPlans` 个计划，上界链 CP-SAT / HiGHS MILP / HiGHS LP / 逐频段容量 / 自由单元容量，gap = 0。
- 解释 B：`QthreeAltRepackNewPlans` ≥ `QthreeNewPlans`，且 ≤ `QthreeFreeCellBound`；重排布局由 `validators.validate_packing` 与既有计划参数不变性检查复核，图 `fig_q3_repack` 给出布局。
- 两种解释都不改变问题 1、2、4 的结果。
