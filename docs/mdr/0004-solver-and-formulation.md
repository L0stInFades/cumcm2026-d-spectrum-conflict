# MDR-0004 求解方法：时频单元格 AtMostOne 模型、CP-SAT 与 HiGHS 交叉验证

日期：2026-09-12 · 状态：已采纳 · 关联问题：问题 2、3、4

## 问题
消解是一个"每计划选一动作、成对不冲突"的组合优化（含最大权独立集为特例，NP-难）。需要选择便于证明最优性、可交叉验证的建模与求解器。

## 备选方案
1. 成对约束 y_{i,o} + Σ_{o'∈C_j(o)} y_{j,o'} ≤ 1：约束数 O(|E|·|O|)，字面量总数达 10^7 量级，Python 建模慢。
2. **单元格约束**：对每个时频单元 (b,t)，覆盖该单元的所有 (计划,动作) 变量至多一个为真（AddAtMostOne）。两个动作冲突当且仅当共享至少一个单元，故与成对约束等价；约束数 ≤ 单元数，字面量总数 ≈ Σ_i |O_i|·w_i d_i n_i ≈ 10^6。
3. 启发式（贪心/局部搜索）：无最优性保证。

## 决策与理由
采用方案 2，用 OR-Tools CP-SAT（多线程，固定随机种子）按词典序逐级求解，每级要求 OPTIMAL；用 HiGHS 建立完全相同的 0-1 线性模型（分离权重单目标）交叉验证目标向量；HiGHS 同时给出各级 LP 松弛下界作为最优性证据；问题 3 的最大装填模型（变量 x_{f,s}，单元格 AtMostOne，目标 max Σx）报告 CP-SAT 解、CP-SAT 界与 HiGHS LP 界及 gap。所有解由独立校验器（单元格集合求交，代码与求解器分离）复核。

## 补充（2026-09-12，实例难度）
探查发现附件实例在每级 60 s 内无法证明最优（撤销 C 一级：可行值 22、下界 8），故：
1. 在单元格约束之外加入两类冗余但加强 LP 松弛与传播的约束：(a) 成对蕴含团 y_{i,o} + Σ_{o'∈C_j(o)} y_{j,o'} ≤ 1（C_j(o) 为计划 j 中与 (i,o) 共享单元的动作，因 j 恰选一动作故为团）；(b) 强制撤销割 z_i + z_j ≥ 1（对任何非撤销动作组合都冲突的计划对）。二者均由单元格行自动推导，不改变可行域。
2. CP-SAT 并行组合中显式加入核心引导（core）子求解器，多线程（24 线程）求解；每级设时间上限，若到时仍未证明最优则以最好可行值固定该级并继续，同时记录该级的证明下界；论文按"值 / 下界 / 状态"如实报告 gap。
3. HiGHS 交叉验证改为相对 CP-SAT 向量：逐级给出 LP 松弛下界与限时 MILP 的对偶界/现任解；若 HiGHS 证明最优，其值必须与 CP-SAT 相同。

## 对结果的影响与验证
随机小实例穷举对照（bench 阶段）验证词典序求解器；同种子重复求解验证确定性；合成实例 n=150…1200 报告求解时间与规模关系。
