# MDR-0009 词典序逐级求解中的现任解保持：上界割、尾部择优与独立标量化前置

日期：2026-09-12 · 状态：已采纳 · 关联问题：问题 2、4（及灵敏度、备选目标方案）

## 问题

MDR-0008 采用"逐级固定最优值 + 现任解热启动"的词典序求解。运行 `20260912-102234-ea48b61` 暴露该实现的三处缺陷，使报告值严重劣于已知可行解：

1. **热启动在第一级之后被丢弃。** 实现在每级结束时执行 `ClearHints()`，再以*该级求解器返回的解*作为下一级的提示。第 1 级只极小化"撤销 A"，其返回解在后续各级上可以任意差。于是 `configs/hints/q2_decisions.json` 中目标向量为 (0,0,**12**,16,37,71,750) 的可行现任解，在进入第 3 级（撤销 C）前已被替换成一个撤销 C 很大的解；该级用尽 600 s 后只回到 **17**。诊断脚本在同一模型、同一固定等式 (撤销 A = 撤销 B = 0)、仅 120 s 下由该提示得到 **12**，证明退化来自提示被覆盖而非实例难度。
2. **没有利用"已知可行解给出上界"这一事实。** 现任解在满足前若干级固定等式时，其第 k 级取值是该级最优值的合法上界；不加割则求解器可能返回比现任解更差的可行值。
3. **交叉验证顺序造成循环。** 分离权重单目标（scheme W 的等价标量化）此前以词典序解作为提示，既丧失独立性，又在本轮得到 (0,0,**14**,…) —— 词典序主解 (0,0,17,…) 被自己的交叉验证击败，论文将出现自相矛盾的两个数字。

## 备选方案

1. 维持现状，只延长时限：无法修复；退化源于提示被覆盖，与预算无关。
2. 每级重建模型并始终以原始提示热启动：丢弃求解过程中发现的更优解，且原始提示在前级最优值严格改善后不再满足固定等式，会失效。
3. **采纳：现任解保持（incumbent-preserving）逐级求解。** 维护一个"完全可行且满足全部已固定等式"的现任解 x\*：
   - 初始化：x\* ← 热启动提示（当且仅当 `hint_is_feasible` 通过）。
   - 第 k 级求解前，令 u_k = L_k(x\*)，加入割 **L_k ≤ u_k**。因 x\* 可行且满足全部已固定等式，u_k 是第 k 级最优值的上界，该割不割去任何最优解，故不改变各级最优值。
   - 求解得到值 v_k ≤ u_k 与解 x̂。若 v_k = u_k（求解器未能改进现任解），则 x\* 与 x̂ 均满足将要加入的等式 L_k = v_k，取二者在**剩余各级** (L_{k+1},…,L_m) 上词典序较小者作为新的 x\*；若 v_k < u_k，则必取 x̂（此时 x\* 已不满足新等式）。
   - 以新的 x\* 重设提示，加入等式 L_k = v_k，进入下一级。
   - 某级在时限内未返回任何解时，不再中断整个求解：以 x\* 的取值 u_k 作为该级值（状态记为 `INCUMBENT`），并令 `all_optimal = false`。
4. 另采纳：**把分离权重单目标移到词典序求解之前**，以文件提示（而非词典序解）热启动；其解若可行且词典序更优，则作为词典序求解的起始现任解。

## 决策与理由

采纳方案 3 + 4。理由：

- **正确性**：割 L_k ≤ u_k 由一个已知可行解导出，是整数规划中标准的现任解剪枝；命题（论文"模型检验"一节）：若 x\* 可行且满足 L_j = v_j (j < k)，则第 k 级受限最优值 ≤ L_k(x\*)，故加入该割后各级最优值不变。尾部择优只在 v_k = u_k 时于两个同样满足全部等式的可行解之间选择，同样不改变任何级的最优值。
- **单调性保证**：报告向量在词典序上永不劣于热启动提示，也永不劣于分离权重解。这消除了"交叉验证击败主解"的自相矛盾，并使 MDR-0008 的灵敏度单调性检查有意义。
- **独立性**：分离权重解不再由词典序解热启动，交叉验证 `WeightedAgree` 因此是真正的独立复核（两种标量化、两次独立搜索）。

各级时限（秒）改为 [30, 30, 600, 300, 300, 300, 300]，分离权重 240，HiGHS LP/MILP 每级 60/30（MDR-0008 的预算在本实现下已不需要那么长）。

## 对结果的影响与验证

- 问题 2 撤销 C 由 17 降至 ≤ 12；问题 4 同样受益。逐级"值 / 证明下界 / 状态"仍如实进入 `tab_q2_solver`、`tab_q4_solver`，`cut` 列记录该级所用的现任解上界。
- 新增性质测试：(i) 返回向量词典序不劣于可行提示（`test_lexicographic_never_worse_than_hint`）；(ii) 在微型实例上与穷举最优一致，且加割前后最优值相同（`bench` 阶段的 24 个微型实例 + `test_incumbent_cut_preserves_optimum`）。
- 独立校验器（MDR-0007）不受影响：它重新对调整后的计划做冲突检测并重算表 1 与目标向量，与求解路径无关。
