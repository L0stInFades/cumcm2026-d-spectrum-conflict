# ADR-0002 运行/阶段/清单模型

日期：2026-09-12 · 状态：已采纳

## 决策
- 工作单元是 `stage @ run_id`；阶段显式声明依赖；同一 run 内共享目录。
- 每个阶段写 `manifest.json`（输入/输出 SHA-256、代码树摘要、配置摘要、参数、环境、包版本、耗时、状态、错误）与 `events.jsonl`。
- 已完成阶段默认跳过（幂等）；`--force` 重跑；`--from-run` 复制旧 run 的依赖输出以继续实验。
- 论文数字通过 `ctx.number()` 登记，`paper` 阶段汇总为 `\val<Key>` 宏；冲突值视为 QA 失败。

## 备选
Airflow/Prefect 等编排系统：功能过重、需常驻服务；DVC：面向数据版本而非阶段清单。

## 后果
可用 `status` 在云端直接审计任何 run；支撑材料自动携带全部清单；代价是每个阶段都要经过 runner，不能"随手跑个脚本"。
