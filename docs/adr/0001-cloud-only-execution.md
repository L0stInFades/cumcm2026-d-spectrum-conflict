# ADR-0001 唯一计算面：所有计算在 Modal 执行

日期：2026-09-12 · 状态：已采纳

## 背景
研究需要在有限时间内产出可复现、可审计的结果；本地机器（Intel Mac）不适合安装重型科学与 TeX 依赖，也不利于环境固定。

## 决策
所有数据解析、计算、测试、绘图、排版、打包在 Modal 的固定镜像中执行；本地仅承担文本编辑、Git、任务提交、下载与散列校验。仓库以只读方式挂载到 `/repo`，产物写入持久卷 `/vol/runs/<run_id>/<stage>/`。

## 后果
- 环境由镜像定义唯一确定，包版本固定，manifest 记录任务 ID 与包版本。
- 探索性分析也必须通过 `tools/cli.py exec` 在云端进行。
- 需要网络与 Modal 账号；离线不可构建。
