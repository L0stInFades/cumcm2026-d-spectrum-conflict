# ADR-0003 三题独立仓库，各自内置同一版本的 Forge 运行时

日期：2026-09-12 · 状态：已采纳

## 决策
A、D、E 三题各自为独立 git 仓库，各仓库内置相同版本（1.0.0）的 `forge/` 与 `pipelines/common/`。不使用共享 Python 包或 git submodule。

## 理由
竞赛支撑材料必须自包含、可独立运行；评审复现不应依赖外部包索引；三题并行推进时互不阻塞。

## 后果
运行时修复需要同步到三个仓库（以补丁形式，记录在各自 CHANGELOG）；`forge/__init__.__version__` 标识版本。
